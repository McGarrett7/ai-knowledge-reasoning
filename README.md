# Renewable Energy Knowledge Graph Reasoning

This repository contains the implementation and experimental datasets used in the paper:

LLM-Assisted Ontology-Based Knowledge Graph Construction and Learning-Based Multi-Agent Reasoning

The repository includes:

- Renewable energy knowledge graph dataset
- Three reasoning algorithms
- Experimental evaluation scripts
- Result tables used in the paper

## Repository Structure

dataset/  
Renewable energy knowledge graph and data splits

algorithms/  
Implementation of reasoning algorithms

experiments/  
Experiment pipeline and evaluation metrics

results/  
Experimental results

figures/  
Architecture diagrams
